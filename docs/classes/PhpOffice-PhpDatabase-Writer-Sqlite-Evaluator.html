Evaluator.php : 31

Evaluation of "standard" SQL expressions with the semantics of SQLite, used to build the entries of the indexes on expressions and of the partial indexes.

Supported: literals, columns, arithmetic, ||, comparisons, IS [NOT] NULL, [NOT] IN (list), [NOT] BETWEEN, [NOT] LIKE, AND, OR, NOT, CASE, CAST and the common scalar functions (lower, upper, length, substr, trim, replace, abs, round, coalesce, ifnull, nullif, iif, instr, min, max). Anything else throws an InvalidArgumentException.
