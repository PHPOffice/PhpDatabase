TextIndexCodes
in package

TextIndexCodes.php : 28

Index keys of the text columns with the "General" sort orders of Access (language 1033): "General - Legacy" (Access 2000-2007) and "General" (Access 2010+).

The code tables (resources/Access/index_codes_*.txt) and the algorithm come from Jackcess (GeneralLegacyIndexCodes, Apache License 2.0). Each line describes the codes of one UTF-16 code unit: S (simple: inline bytes), I (international: inline and extra bytes), U (unprintable bytes), P (unprintable, extra byte modifier), Z (international with a "crazy" flag), G (significant), X (ignored).
