AccessBuilder
in package

AccessBuilder.php : 33

Builder of Jet 4 (.mdb, Access 2000) and ACE (.accdb, Access 2007+) databases.

Like Jackcess, the database starts from an empty database created by Access (resources/Access/empty*.gz): its pages are kept, the user tables are appended (definitions, data pages, long value pages, usage maps, B-trees of the indexes) and the system tables are updated: new rows in MSysObjects (tables, relationships, properties), MSysACEs (permissions) and MSysRelationships, all their indexes being rebuilt.
