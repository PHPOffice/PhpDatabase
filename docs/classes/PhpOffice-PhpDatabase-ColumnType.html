ColumnType.php : 26

Logical column types, independent of the file format.

PHP values held in the rows: BOOLEAN => bool, TINYINT/SMALLINT/INTEGER/BIGINT => int, FLOAT/DOUBLE => float, DECIMAL => numeric string, TEXT/LONGTEXT => string (UTF-8), DATE/TIME/DATETIME => DateTimeImmutable, BLOB => binary string, GUID => "{XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}", HYPERLINK => string ("text#address#subaddress#" like Access), ATTACHMENT => array of Attachment. null is always allowed. A multi-valued column (Column::setMultiValued()) holds an array of values.
