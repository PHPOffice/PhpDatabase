DataFile
in package

DataFile.php : 28

Reader of the rows of the CACHED tables of HSQLDB 1.8 (database/data file of the ODB files).

A row is: int size, one AVL node per index (int balance, int left, int right, int parent), then for each column a "not null" byte followed by the value.
