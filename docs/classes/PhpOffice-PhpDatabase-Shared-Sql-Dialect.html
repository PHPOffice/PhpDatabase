in package
  • Application

FinalYes
Dialect.php : 28

Conversion of SQL statements and expressions (views, check constraints, defaults...) between the dialects of the formats and the "standard" SQL of the object model:

  • standard: "identifier", 'string', a || b, DATE '2024-01-31', CURRENT_DATE, LIMIT n;
  • SQLite: also identifier and [identifier];
  • HSQLDB 1.8: unquoted identifiers are upper case: the writer quotes them all;
  • Access: [identifier], "string", a & b, #2024-01-31#, Date(), Now(), SELECT TOP n, Like "a*".

The conversion works on tokens and keeps the layout (spaces, comments) of the statement. Functions specific to an engine (IIf, Nz, strftime...) are kept as is.
