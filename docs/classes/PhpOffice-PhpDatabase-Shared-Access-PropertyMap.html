PropertyMap.php : 23

Properties of an object of the catalog (column "LvProp" of MSysObjects): the properties of the object itself (Description...) and of each column of a table (Required, DefaultValue, Description...).

Format: "MR2\0", a block with the names of the properties, then one block per map (type 0x00: object, 0x01: column), each value being written like a column value.
