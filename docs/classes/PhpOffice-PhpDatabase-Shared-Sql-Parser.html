Parser.php : 34

Parser of the statements found in the files: CREATE TABLE, CREATE INDEX, CREATE VIEW, CREATE TRIGGER, ALTER TABLE ... ADD CONSTRAINT, INSERT INTO ... VALUES and DELETE FROM ... WHERE.

Expressions (checks, defaults, views...) are converted to the "standard" SQL of the object model.
